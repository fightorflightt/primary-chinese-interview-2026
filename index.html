02INTERVIEW PROCESS

完整面试流程

候考与身份核验

按准考证规定时间到达考点，携带准考证及符合规定的有效身份证件。

抽题 · 小学语文1题

使用面试测评系统随机抽取1道试题，打印题目清单，重点查看具体教学要求。

备课 · 20分钟

确定课型、目标与重难点，写教学简案、课堂问题和板书设计。

结构化规定问题 · 约5分钟

考官随机抽取2道题，考查教育观、临场处理、思维与表达。

试讲 · 10分钟

模拟真实课堂，完成导入、学习活动、评价、巩固与总结。必须“讲课”，而不是“说课”。

答辩 · 约5分钟

围绕你的试讲、教学目标与方法、语文知识进行回答。

离场与评分

按要求提交教案并离场。候考排队时间不计入以上40分钟。

关键区别：“说课”是告诉考官你打算怎样教；“试讲”是把考官当作观察者，直接给想象中的学生上课。
说课：“我会让学生自由朗读。”
试讲：“请同学们自由朗读这一自然段，圈出描写荷花姿态的词语。”

三个环节分别看什么？

环节考查重点训练抓手
结构化教育理念、分析与处理问题、表达逻辑观点→原因→措施→反思
试讲目标明确、方法适切、知识准确、活动有效、评价具体围绕一个重点设计2个问题与1个活动
答辩解释设计依据、发现不足、展示学科理解准备“为何这样设计／如何改进”

让课堂像课堂：提问—等待—反馈—追问

不建议这样讲

“接下来我会让学生朗读课文，接着分析句子，最后做课堂总结。”

这属于描述教学安排，没有呈现真实教学行为。

建议这样讲

“请大家自由朗读第二自然段，画出你最喜欢的一句话。……这位同学找到了‘冒’字，你从这个字感受到了什么？”

有任务、问题、模拟学生回答、评价与追问。

核心原则：重视内容准确和教学目标，不要机械套模板。若题目要求“指导生字书写”，必须展示书写指导；若要求“体会语言之美”，重点应放在词句表达、朗读和感受。
04LESSON TYPES

六类小学语文课型

先学会阅读、识字、古诗三类，再掌握习作、口语交际和文言文。练习课文是示例，不代表押题。

课型 A · 优先练习

阅读课

流程：情境导入 → 初读整体感知 → 品读关键词句 → 朗读体会 → 迁移总结

  1. 选一个重点段落与核心问题
  2. 指导学生从关键词句找证据
  3. 通过朗读、想象、交流感受表达
  4. 给予具体评价，不能只说“很好”
《荷花》：“‘冒’字好在哪里？它让你看到荷花怎样生长？”引导学生联系语言展开想象。

训练素材：《荷花》《秋天的雨》《搭船的鸟》。

课型 B · 低年级关键

识字写字课

流程：情境导入 → 认读生字 → 字形、字义识记 → 书写指导 → 游戏巩固

  1. 先读准字音与声调
  2. 偏旁归类、形声字、加一加等识字
  3. 结合图片、动作、语境理解字义
  4. 观察结构和占格，示范关键笔画
《日月明》：“‘日’和‘月’组合成了‘明’，谁能给‘明’组词？”随后示范观察结构与书写。

训练素材：《日月明》《小青蛙》。

课型 C · 高频备考方向之一

古诗词课

流程：知题与背景 → 读准字音 → 理解诗句 → 想象画面 → 体会情感 → 诵读积累

  1. 保证朗读节奏和读音准确
  2. 用注释与语境理解关键字词
  3. 引导学生想象诗中画面
  4. 以朗读表达情感，避免逐字翻译贯穿全课
《山行》：“‘停车坐爱枫林晚’中的‘坐’是什么意思？”解释“因为”，再想象傍晚枫林。

训练素材：《山行》《望庐山瀑布》《望天门山》。

课型 D · 掌握基本方法

习作课

流程：明确习作任务 → 选材与构思 → 方法示范 → 片段练习 → 分享评价

  1. 把抽象的写作要求拆成可操作方法
  2. 让学生从生活中挑选真实素材
  3. 展示一小段示例并解释写法
  4. 让学生口头练习或修改片段
《猜猜他是谁》：突出一个人的典型外貌和特点，避免把面部特征从头到脚罗列。
课型 E · 体现交际

口语交际课

流程：创设真实情境 → 明确交际要求 → 示范与交流 → 角色练习 → 评价改进

  1. 设计有明确交际对象的任务
  2. 强调倾听、礼貌、表达清楚
  3. 安排角色扮演与对话反馈
《商量》：“如果想借同学的画笔，怎样说更合适？对方拒绝时怎样回应？”
课型 F · 适当覆盖

文言文课

流程：初读正音 → 借助注释理解 → 梳理故事 → 感悟道理 → 朗读积累

  1. 以小学学生可理解的语言解释
  2. 借助注释、插图和动作帮助理解
  3. 不要照搬诗歌课的画面想象套路
《司马光》：结合“瓮”的意思、故事人物动作，理解故事过程与品质。

四张最有用的课型卡片

把阅读、识字、古诗、习作/口语交际各浓缩为一张卡。每张只记录：教什么→怎样导入→核心问题→学生活动→具体评价→板书。不要逐篇背全文。

06STRUCTURED Q&A

结构化问答：六类题与答题思路

现场通常为2道规定问题、约5分钟。练习时每题先思考15—20秒，再作答约1.5—2分钟。不要机械背逐字稿。

题型典型问题答题线索
应急应变上课时学生突然哭了怎么办？稳定现场→核实情况→处理→跟进
教育教学学生总是上课走神怎么办？寻找原因→差异化引导→观察改进
人际沟通家长质疑你的教学能力怎么办？倾听→核实→沟通措施→反馈
职业认知为什么想当小学语文老师？职业认识→个人匹配→行动计划
综合分析如何看待减轻学生作业负担？明确观点→分析意义→实践落地
班级管理两名学生发生争执怎么办？确保安全→了解事实→教育引导→预防
情境题通用思路：表明态度 → 分析原因 → 采取具体措施 → 跟进与反思。
这是一种组织语言的方法，实际作答要针对题目判断是否需要调整。

练习题与示范思路（点击展开）

Q1：学生上课总是不认真听讲怎么办？

态度：我不会立即批评，而会先判断原因。

原因：可能是疲劳、内容过难、注意力特点或课堂参与不足。

措施：课堂用提问和具体任务邀请参与；课后个别沟通，必要时与家长协同；同时反思教学活动是否适切。

跟进：持续观察学生参与度，调整方法。

Q2：家长说你布置的作业太多，怎么办？
首先倾听具体反馈，不立即争辩；核查作业量、完成时长和是否存在重复低效练习；优化分层和作业设计；向家长说明调整方案并继续收集反馈。注意不简单地把责任推给家长或学生。
Q3：学生在课堂上发生争吵，怎么办？
先确保课堂安全，必要时将双方适当分开；恢复课堂秩序；课后分别了解事实，引导表达感受和需求，公平处理；通过班级规则、沟通技巧训练预防再次发生。若涉及伤害或严重欺凌，及时按学校机制报告处理。
Q4：为什么选择做小学语文教师？
可以从语文教学的育人价值出发：识字阅读是学生学习的基础，语言表达和阅读体验对其成长很重要。结合自己的实际准备和优势，说明愿意持续学习课程标准、教学设计与儿童心理，而不是只说“喜欢孩子”。
Q5：你如何看待“双减”背景下的教学？
应提高课堂教学质量和作业有效性，避免把学习任务机械转移到家庭；通过明确目标、针对性练习、个别反馈实现减负提质。涉及具体政策表述时，以现行正式政策为准。
Q6：试讲答辩——为什么要安排小组讨论？
因为该教学点需要学生表达不同理解。先独立思考，再小组交流，有助于人人有话可说、在倾听中修正认识。讨论须有明确问题、时间要求和交流反馈，而不是为了形式热闹。

答题时要避免

  • 空话多：只说“耐心沟通、积极引导”，没讲具体怎么做。
  • 反应过度：把普通课堂问题直接交给学校领导；但安全风险要及时上报。
  • 忽视学生尊严：以羞辱、体罚或公开标签化解决问题。
  • 偏题背诵：不看问题类型，硬套一个万能开头。

每日建议：结构化2—4题，录音回听后只保留3—4个关键词，第二天脱稿复答。

“靠窗这位同学，你来说一说……（稍作停顿）你发现了‘冒’这个字。它让我们仿佛看到荷花有力量地向上生长。请大家再把这句话读一遍。”

无需变声扮演学生；通过自然停顿、复述学生观点、追问和评价体现课堂互动即可。

09MOCK PRACTICE

模拟训练与复盘

一轮完整模拟怎么做？

  1. 随机抽一篇陌生课文：不预先看参考教案，只给自己题目清单。
  2. 20分钟：独立完成教案，不查资料、不反复修改。
  3. 约5分钟：回答2道结构化问题。
  4. 10分钟：站立录像试讲，包括板书及师生互动。
  5. 约5分钟：回答2—3个答辩问题。
  6. 复盘：回看视频，对照以下项目检查，下一轮只集中修正2个最突出的问题。
